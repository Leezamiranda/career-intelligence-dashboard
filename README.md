# Career Intelligence Dashboard

## What It Does
A data pipeline and analytics tool that aggregates job postings, 
skill requirements, and market trends to support strategic job search 
decisions in PM, Solutions Engineering, and Strategy & Operations roles.

## Why I Built This
I'm a CS student and operations leader transitioning into tech roles. 
Rather than job searching blind, I built this tool to surface patterns 
in what companies actually hire for and where my profile has the 
strongest signal.

## Tech Stack
- **Database:** PostgreSQL
- **Backend/ETL:** Python (psycopg2, requests, BeautifulSoup)
- **Analysis:** SQL, Pandas
- **Visualization:** Tableau Public
